# Student Scholarship & Grant Information Portal

A beginner-friendly academic project prototype built using HTML, CSS and JavaScript.

## Features
- Responsive home page
- Scholarship search and filters
- Eligibility checker
- Demo student registration/login
- Student dashboard
- Save/bookmark scholarships using browser localStorage
- Admin dashboard prototype
- Sample scholarship data

## How to run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server.
4. Explore the pages using the navigation bar.

## Important
The scholarship records in this frontend prototype are sample/demo records. For a real deployment, replace them with verified information and official application URLs.

## Future version
The frontend can later be connected to a Java Spring Boot backend and MySQL database.
